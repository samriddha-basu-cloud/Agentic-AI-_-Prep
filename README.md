# SCM·AI Prep — Agentic AI Applications in Operations & SCM

A minimal static website of exam notes for **Agentic AI Applications in Operations and Supply Chain Management** (MBA OM). It is built from the 20 session decks, the 9-unit syllabus and the two past papers.

The exam is case-based with straightforward numericals and a heavy emphasis on the Chain Reaction simulation, so the site is organised around that. It has:
- an **exam playbook** (numbered-assumptions format, answer skeleton, data triage, framework picker);
- both **past papers solved in full** (Trishul Consumer Products; Kaveri Motors / Chain Reaction);
- a **Chain Reaction playbook** (rules, rounds, archetypes, lessons, strategy rulebook);
- all **37 course frameworks**;
- **50 worked numericals**;
- **13 in-depth chapters** plus SCM fundamentals;
- a **case library**;
- **three mock papers** with model answers;
- a 45-question **Q&A bank**;
- **85 MCQs**, including every class question from Sessions 1–20;
- a **glossary**, **flashcards**, a **quiz** and **rapid revision**.

There is no build step to run the site and there are no dependencies: plain HTML, CSS and JavaScript.

## What's inside
```
index.html            the website (dashboard, sidebar, search palette, self-test, flashcards, quiz)
assets/style.css      styling
assets/app.js         loads and renders the notes
assets/notes.js       all notes bundled into one file (generated by build.py)
assets/marked.min.js  Markdown renderer (marked v12, MIT licence)
notes/*.md            the original Markdown notes (also readable on GitHub)
build.py              re-bundles notes/*.md into assets/notes.js
vercel.json           Vercel settings
```

## Preview on your computer
Double-click `index.html`. It works offline because the notes are bundled in `assets/notes.js`.

## Edit the notes
Edit any file in `notes/`, then run:
```bash
python3 build.py
```
Commit both the `.md` file and `assets/notes.js`.

## Host it on Vercel
1. Go to https://vercel.com/new and sign in with GitHub.
2. Click **Import** next to the `Agentic-AI-_-Prep` repository (grant Vercel access to it if asked).
3. Framework preset: **Other**. Leave the build command and output directory empty. The root directory is `./`.
4. Click **Deploy**.

GitHub Pages also works: repository **Settings → Pages → Deploy from a branch → main / root**.

- `J` / `K`: next / previous page
- `B`: bookmark
- `D`: mark done
